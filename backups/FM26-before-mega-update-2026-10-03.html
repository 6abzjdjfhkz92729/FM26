Construis ta carrière de manager : choisis ton club, ton staff, ton style de jeu et pilote chaque détail entre deux matchs.

Base du jeu
Moteur de match déterministe + aléatoire, mercato simulé, boîte mail, joueurs avec réponses contextuelles, conférences de presse, supporters, conseil d'administration, réputation et historique.
Cette version fonctionne sans serveur : la carrière est sauvegardée dans le navigateur. Les conversations joueurs sont des agents simulés (aucune clé API n'est exposée).
